## 一、 环境依赖与准备

### 1. Python 运行环境
* **版本要求**：Python 3.6 及以上版本。
* **官方下载**：[Python 官方网站](https://www.python.org/)
* **注意事项**：Windows 安装过程中，务必勾选 **`Add Python to PATH`**（将 Python 添加至系统环境变量）。
* **验证环境**：
  按快捷键 <kbd>Win</kbd> + <kbd>R</kbd> 输入 `cmd` 回车，执行以下命令验证：
  
  ```bash
  python --version
  ```

### 2. 核心视频播放器
脚本原生支持并预置了常见的高性能本地播放器，可根据个人需求自由搭配：
* **MPC-HC**：轻量高效，常见于 [K-Lite Codec Pack](https://codecguide.com/)。
* **mpv**：高画质自定义渲染器首选（支持各类着色器与滤镜脚本）。
* **PotPlayer / VLC**：常见的通用格式全能播放器。

## 二、 播放器挂载与路径配置

打开 `video_launcher.py` 文件，在脚本顶部的 **`PLAYERS` 字典** 区域即可按需调整可执行文件路径或挂载更多播放器：

```python
PLAYERS = {
    "1": {
        "name": "MPC-HC",
        "path": r"C:\Program Files (x86)\K-Lite Codec Pack\MPC-HC64\mpc-hc64_nvo.exe"  # MPC-HC 真实路径
    },
    "2": {
        "name": "mpv", 
        "path": r"D:\Data\Player\mpv\mpv.exe"                                          # mpv 真实路径
    },
    # 如需挂载第 3、4 个播放器，取消注释并填入对应路径即可：
    # "3": {
    #     "name": "PotPlayer",
    #     "path": r"C:\Program Files\DAUM\PotPlayer\PotPlayer64.exe"
    # },
}
```

> **💡 路径提示**：
> 1. Windows 路径前务必保留英文字符 `r`（如 `r"C:\..."`），避免转义符引发路径错误。
> 2. 路径必须直接指向以 `.exe` 结尾的可执行文件。

## 三、 功能模态详解

启动脚本后，控制台会提供交互式功能菜单：

### 模态 1：不同视频 + 自主选择播放器（批量调起）
> **适用场景**：需要连续排查多个视频文件、剧集批量抽检、或者一口气将多个片源挂起至指定的某个播放器中。

* **工作流程**：
  1. 交互挑选本次任务想要调用的特定播放器。
  2. 录入待播放的视频路径（支持一次性批量添加多个文件）。
  3. 支持随时进入队列管理菜单，查看、单项删除或清空已添加的列表。
  4. 确认后，脚本通过后台进程逐一唤起播放器实例，各窗口互不干扰。

---

### 模态 2：相同视频 + 不同播放器（画质/渲染器同屏对比）
> **适用场景**：压制对比测试、播放器渲染滤镜（如 madVR vs mpv 默认 / Anime4K 着色器）效果对比、同源色彩还原差异横评。

* **工作流程**：
  1. 录入需要测试比对的单个视频文件路径。
  2. 脚本自动探测当前所有已就绪的可用播放器。
  3. 确认后，脚本会在瞬间**同时拉起所有可用播放器**并共同载入该视频。
  4. 用户可直接在屏幕上并排摆放两个播放器窗口，进行逐帧渲染与画质细节的肉眼对比。

---

### 模态 3：检查播放器挂载与环境状态
> **适用场景**：更换设备或移动了播放器安装目录后，快速巡检各播放器路径的有效性。

* 启动后会自动轮询 `PLAYERS` 列表中各配置项的文件存在状态。
* 绿灯（`🟢 可用`）即代表路径挂载成功；若提示 `🔴 路径不存在`，则需检查对应盘符及目录。

## 四、 快捷录入与操作技巧

* **文件直接拖拽**：在控制台提示输入路径时，无需手动键盘打字，直接将电脑里的视频文件**用鼠标拖拽进命令行窗口**，按回车即可自动识别并清洗引号。
* **多路径批量混贴**：在模态 1 中录入队列时，支持一次性粘贴由空格分隔的多个文件路径。
* **进程解耦**：脚本唤起播放器后采用独立子进程分离运行，即使关闭黑色的 Python 控制台窗口，已经打开的播放器也不会被连带关闭。

## 五、 常见问题与排障指南

| 常见问题                           | 排查原因                                               | 解决方案                                                     |
| :--------------------------------- | :----------------------------------------------------- | :----------------------------------------------------------- |
| **双击脚本窗口一闪而过**           | 系统未安装 Python 或未勾选 PATH 环境变量               | 重新安装 Python，并在首屏勾选 **Add Python to PATH**。       |
| **提示“未检测到任何可用的播放器”** | 脚本内预设的 `.exe` 路径与本机实际存放路径不符         | 使用记事本或编辑器打开脚本，检查并纠正 `PLAYERS` 字典中的文件绝对路径。 |
| **拖入视频提示“目标文件不存在”**   | 文件名包含极端特殊转义字符或路径带有额外非法符号       | 确认源文件已被正确下载且没有被其他程序独占重命名；可尝试将视频放入简单路径测试。 |
| **播放器只打开了一个窗口**         | 部分播放器（如 PotPlayer/MPC）设置了“只允许单进程运行” | 进入对应播放器内部设置，将“多进程运行”或“允许多个实例同时运行”选项勾选开启。 |
